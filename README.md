# Sentiment Analysis using LSTM and IMDb Dataset

A Deep Learning-based **Sentiment Analysis** project that classifies movie reviews as **Positive** or **Negative** using the **IMDb Movie Reviews Dataset**. This project uses **LSTM (Long Short-Term Memory)** networks to understand text sequences and predict sentiment with high accuracy.

The project covers the complete NLP and Deep Learning workflow including:

* Text preprocessing and tokenization
* Sequence padding and vocabulary creation
* Building and training an LSTM model
* Binary sentiment classification
* Model evaluation using accuracy and loss metrics
* Predicting sentiment for custom user reviews

This repository is beginner-friendly and helps in understanding the fundamentals of **Natural Language Processing (NLP)** and **Deep Learning** using real-world movie review data.
